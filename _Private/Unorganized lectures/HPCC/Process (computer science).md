A **process**, in computer science, is an independent sequence of instructions and the ensemble of resources needed for their execution. This includes the source code defining the instructions, as well as memory allocation, [[file system]] access, possibly network access and so on. Informally, a process is a "program that's running". An [[operating system]] manages many processes running at the same time, both for system management and for user interaction. The same program can also be executed multiple times simultaneously: each execution is said to be an **instance** of the program, each of which is a separate process.
