## Parameter estimation
We can estimate the number of parameters and the number of distinct linear regions of a neural network with one hidden layer. Call $D_\text{in}$ the dimension of the input and $D_\text{hid}$ the dimension of the hidden layer. Then, $n=?$.

The number of linear regions $N_\text{lin}$ is more difficult. We know that this number is bounded by $2^{D_\text{in}}\leq N_\text{lin}\leq 2^{D_\text{hid}}$ and we can estimate it using a sum of [[Binomial theorem|binomial coefficients]]:
$$N_\text{lin}\simeq \sum_{i=0}^{D_\text{in}} \begin{pmatrix}D_\text{hid} \\ i\end{pmatrix}$$
This formula only applies when $D_\text{in}\leq D_\text{hid}$. As you can guess by the binomial coefficients (which are factorials internally), $N_\text{lin}$ increases extremely fast as the dimensionalities go up, meaning that even networks with only a few hundred inputs and hidden units can distinguish between an astronomical number of linear regions. For example, for $D_\text{in}=100$ and $D_\text{hid}=500$, $N_\text{lin}$ is in the order of $\sim 10^{100}$ regions! This extreme scaling contributes to the incredible expressivity of the neural network architecture, but it also makes these networks difficult to inspect: how do you analyze a space that is $100\times500$ dimensional for $\sim10^{100}$ regions?
## Data distribution
The input data exists in a (generally) high-dimensional space. We can call this **input space**. As the purpose of a neural network is to run a transformation on the input data, understanding how this data is distributed in input space helps us understand what the model is doing.

Since input space is high-dimensional and most realistic data is not [[Uniform distribution|uniformly distributed]], we'll have regions that are more dense than others. Experimentally, we find that the higher the dimensions go, the more of input space is *completely empty*. This phenomenon is known as the **[[curse of dimensionality]]** and it is due to the fact that the number of points required to fill a volume increases exponentially with dimensionality. Therefore, in realistic input dimensionalities (hundreds or thousands, possibly much more depending on the problem), data only occupies a very small region of the input space: input space is *sparse*.
