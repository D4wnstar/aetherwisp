A **database** (**DB**) is a collection of data that is structured in a homogeneous way and is stored permanently. Homogeneous structure implies the need of a **data model**, an abstract description of how the data is intended to be stored. The most common data model is the [[relational model]], used by the popular [[SQL]] database architecture, which emphasizes how data relates to other data.
